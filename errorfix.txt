# Error Fix Plan — duplicate React keys in TeacherWorkloadChart

## Diagnosis

All reported console errors share ONE root cause:
Production teacher data has duplicate `short_name` values (initials like `MH`,
`SA`, `MR`, `AR`...). The admin dashboard keys the workload chart cells on
`short_name`, so every collision emits a "two children with the same key"
warning — collectively the 27 errors.

- `src/app/admin/page.tsx:166` -> `{ name: t.short_name, ... }`
- `src/components/admin/dashboard/teacher-workload-chart.tsx:63` -> `<Cell key={d.name} .../>`

Fix = stop using teacher `short_name` as identity/label on the frontend; key on
teacher `id`, display `full_name`.

Decisions (confirmed):
- Teachers only — subject `short_name` codes (Bng, Eng) stay untouched.
- Keep DB column `teachers.short_name` (NOT NULL); server actions auto-derive
  initials from `full_name`. No schema/seed/import-SQL changes.
